Sistema de controle de serviços para freelancers que trabalham em atrações de parques e eventos, desenvolvido em Java. O projeto permite cadastrar serviços, calcular valores por horas trabalhadas, adicionar custos de transporte e adicional noturno, além de gerar um relatório com os totais a receber. Utiliza Programação Orientada a Objetos (POO), encapsulamento, herança, métodos e ArrayList.
